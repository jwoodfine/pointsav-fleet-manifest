# 🚢 FLOTA DE DESPLIEGUE POINTSAV
**Entidad:** PointSav Digital Systems™ (El Proveedor)
**Función:** Demostración Genérica y Prueba Operativa

---
## I. MANDATO ARQUITECTÓNICO
Este repositorio demuestra cómo un Cliente despliega la infraestructura PointSav. Utiliza un lenguaje de "demostración genérica", abstrayendo implementaciones complejas de Rust y a nivel de sistema operativo en conceptos comprensibles (`os-totebox`, `os-mediakit`). Esta flota está diseñada para demostrar el modelo Proveedor/Cliente ante auditores técnicos y socios institucionales.

## II. ACTIVOS CONTENIDOS
* `media-marketing-landing`: La red de entrega de contenido (Edge Delivery) orientada al público que demuestra analítica sin cookies (Zero-Cookie).
